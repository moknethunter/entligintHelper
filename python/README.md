# نواة دليل بلغة Python

تعمل عبر Python 3.10 أو أحدث باستخدام المكتبة القياسية. تقرأ دليل الحسابات والصناديق وميزان المراجعة من ملف SQLite أتاحه مسؤول المصدر. تعرض اسم المصدر واسم الجدول أو العرض ووقت القراءة والسجلات المستند إليها. يُحسب الفرق بين المدين والدائن لكل عملة بدقة عشرية. تُعرض حالة مستقلة للفترة التي لا تحتوي بيانات أو للنتيجة التي تجاوزت الحد، وتُترك الإجماليات فارغة في الحالتين.

## مساحة العمل العربية

من جذر المستودع، شغّل التطبيق ثم افتح رابط الجلسة الذي يطبعه في الطرفية على الكمبيوتر نفسه:

```bash
python python/desk.py --demo
```

تعرض التجربة سجلات حسابات وصناديق وميزان مراجعة تجريبيًا للفترة من 2026-11-01 إلى 2026-11-30. تعرض اللوحة مصدر كل نتيجة وفترتها ووقت قراءتها، وتتيح تنزيل السجلات المكتملة بصيغة CSV. احتفظ بالمصدر والتقرير المعروض عند التحقق من الأرقام التي قد يقرّبها تطبيق الجداول تلقائيًا عند استيراد CSV.

لتشغيلها مع ملف مصرح به من المسؤول:

```bash
python python/desk.py --database company.db --source-label "دفتر الشركة" --approved --workspace daleel-workspace.db
```

- ملف المصدر للقراءة فقط. ملف مساحة العمل مستقل واختياري، ويجب أن يكون داخل مجلد يقتصر الوصول إليه على المستخدم المخوّل.
- تحفظ مساحة العمل الإجراء وعنوانه وخطواته ومرجع مراجعته عند اختيار «حفظ الإجراء». توجد قوالب للمحاسبة والمراجعة الهندسية والقانونية. يكتب المختص الخطوات ويعدلها ثم يعتمدها خارج التطبيق. تساعدك أداة مقارنة المستندات على توثيق ما تغير بين نسختين من المواصفات أو العقود النصية.
- إذا فعّلت خيار التعلّم أثناء الجلسة، تُحفظ عدادات أنواع التقارير المكتملة ويظهر النوع الأكثر استخدامًا عند العودة. لا تُنسخ السجلات والمبالغ والفترات إلى ملف الذاكرة تلقائيًا، ويمكن مسح التفضيل وحذف الإجراءات من الواجهة.
- تقارن الأداة ملفات TXT أو Markdown بترميز UTF-8 حتى 32 كيلوبايت و1600 سطر لكل نسخة. تعالج النصوص مؤقتًا داخل الخدمة المحلية وتعرض الإضافات والحذف والتعديل بأرقام الأسطر. تتناول المقارنة محتوى الأسطر؛ قرار الأثر الفني أو القانوني مسؤولية المختص.
- الخدمة مرتبطة بعنوان الاسترجاع المحلي فقط، وتتحقق من أصل الطلب ورمز الجلسة قبل القراءة. احتفظ بالرابط داخل جهازك؛ لإعادة فتح الصفحة استخدم الرابط الكامل من نافذة التشغيل. أوقف الخدمة بإغلاقها من الطرفية.
- ذاكرة التجربة مؤقتة. أضف `--workspace` لتجربة الحفظ بين التشغيلات.

## وضع التشغيل وخطوة الطرح

هذه النسخة موجهة للتجربة المحلية على جهاز واحد مع مستخدم مخوّل. قبل طرحها لفريق أو عميل، يُستكمل موصل البرنامج الفعلي واختباره ببيانات مرخصة، ثم تُحدد إدارة المستخدمين والأدوار وعزل العملاء، وسجل التدقيق والاحتفاظ بالبيانات، والتوزيع والترخيص والدعم. تظل الموافقة التشغيلية والفنية والقانونية لدى أصحاب الصلاحية والتخصص. لا تعرّض هذه الخدمة المحلية للشبكة أو الإنترنت.

شغّل اختبارات Python من مجلد `python`:

```bash
python -m unittest discover -s tests -v
```

## تجربة سطر الأوامر

من جذر المشروع، أنشئ ملفًا تجريبيًا جديدًا:

```bash
python -c "import sqlite3; from pathlib import Path; p = Path('daleel-demo.db'); p.touch(exist_ok=False); c = sqlite3.connect(p); c.executescript(Path('python/demo.sql').read_text(encoding='utf-8')); c.close()"
python python/daleel.py --database daleel-demo.db --source-label Demo --approved accounts
python python/daleel.py --database daleel-demo.db --source-label Demo --approved cashboxes
python python/daleel.py --database daleel-demo.db --source-label Demo --approved trial-balance --start 2026-11-01 --end 2026-11-30
```

## ربط مصدر فعلي

يوفر مسؤول النظام ملفًا مستقلًا للكيان الذي يحق للمستخدم الاطلاع عليه، أو نسخة يصدّرها البرنامج لهذا الغرض. تُطابق أسماء الجداول أو العروض والأعمدة المخطط في `demo.sql`. يوفّر المصدر صفوف ميزان المراجعة لكل فترة معتمدة ويخزن المبالغ كنصوص عشرية ورموز العملات على هيئة ثلاثة أحرف. معرّف المصدر الذي يدخله المستخدم تسمية، وتاريخ القراءة يصف وقت جلب البيانات. تعتمد حداثة الأرقام واكتمالها على المصدر وفترة التصدير.

تنفذ النواة استعلامات ثابتة ذات معاملات وتفتح الملف للقراءة فقط. يجب أن تكون القيم المعروضة نصية وتطابق أنواع الأعمدة في المثال. خيار `--approved` يسجل إقرار المستخدم في هذا التشغيل، وتظل صلاحية قراءة الملف والعزل بين الكيانات من مسؤول النظام ونظام التشغيل. إذا كان البرنامج يوفر API أو قاعدة بيانات أخرى، يلزم موصل مخصص وفق آلية التفويض التي يوفرها ذلك البرنامج. إضافة Chrome ونواة Python تعملان حاليًا كأداتين مستقلتين.
