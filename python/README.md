# نواة دليل بلغة Python

تعمل عبر Python 3.10 أو أحدث باستخدام المكتبة القياسية. تقرأ دليل الحسابات والصناديق وميزان المراجعة من ملف SQLite أتاحه مسؤول المصدر. تعرض اسم المصدر واسم الجدول أو العرض ووقت القراءة والسجلات المستند إليها. يُحسب الفرق بين المدين والدائن لكل عملة بدقة عشرية. تُعرض حالة مستقلة للفترة التي لا تحتوي بيانات أو للنتيجة التي تجاوزت الحد، وتُترك الإجماليات فارغة في الحالتين.

## تجربة محلية

من جذر المشروع، أنشئ ملفًا تجريبيًا جديدًا:

```bash
python -c "import sqlite3; from pathlib import Path; p = Path('daleel-demo.db'); p.touch(exist_ok=False); c = sqlite3.connect(p); c.executescript(Path('python/demo.sql').read_text(encoding='utf-8')); c.close()"
python python/daleel.py --database daleel-demo.db --source-label Demo --approved accounts
python python/daleel.py --database daleel-demo.db --source-label Demo --approved cashboxes
python python/daleel.py --database daleel-demo.db --source-label Demo --approved trial-balance --start 2026-11-01 --end 2026-11-30
```

## ربط مصدر فعلي

يوفر مسؤول النظام ملفًا مستقلًا للكيان الذي يحق للمستخدم الاطلاع عليه، أو نسخة يصدّرها البرنامج لهذا الغرض. تُطابق أسماء الجداول أو العروض والأعمدة المخطط في `demo.sql`. يوفّر المصدر صفوف ميزان المراجعة لكل فترة معتمدة ويخزن المبالغ كنصوص عشرية ورموز العملات على هيئة ثلاثة أحرف. معرّف المصدر الذي يدخله المستخدم تسمية، وتاريخ القراءة يصف وقت جلب البيانات. تعتمد حداثة الأرقام واكتمالها على المصدر وفترة التصدير.

تنفذ النواة استعلامات ثابتة ذات معاملات وتفتح الملف للقراءة فقط. خيار `--approved` يسجل إقرار المستخدم في هذا التشغيل، وتظل صلاحية قراءة الملف والعزل بين الكيانات من مسؤول النظام ونظام التشغيل. إذا كان البرنامج يوفر API أو قاعدة بيانات أخرى، يلزم موصل مخصص وفق آلية التفويض التي يوفرها ذلك البرنامج. إضافة Chrome ونواة Python تعملان حاليًا كأداتين مستقلتين.
