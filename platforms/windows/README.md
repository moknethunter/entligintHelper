# دليل لويندوز

1. فك ضغط الحزمة بالكامل في مجلد واحد.
2. افتح `Daleel.cmd` لتشغيل التجربة. تحتاج هذه الحزمة Python 3.10 أو أحدث على ويندوز.
3. تفتح واجهة دليل العربية في متصفح الكمبيوتر. إذا لم يُفتح المتصفح تلقائيًا، انسخ الرابط الذي تظهره نافذة التشغيل وافتحه على نفس الجهاز.
4. لربط بيانات فعلية، اسحب **نسخة SQLite المصرّح لك بقراءتها** على `Daleel.cmd`. تعتمد القراءة على مخطط دليل الموضح في `python/demo.sql`.

يحفظ دليل تفضيلات التقرير والإجراءات في مجلد المستخدم المحلي `%LOCALAPPDATA%\Daleel`. أبقِ نافذة التشغيل مفتوحة أثناء الاستخدام وأغلقها عند الانتهاء.

## بناء ملف EXE محمول

تنفذ مهمة Windows في GitHub Actions هذه الخطوات ببيئة Windows وتنتج ملف `Daleel.exe`. من جذر المستودع، يمكن تكرار البناء يدويًا:

```bat
py -3 -m pip install pyinstaller==6.17.0
py -3 -m PyInstaller --noconfirm --clean --onefile --name Daleel --add-data "python/web:web" --add-data "python/demo.sql:." python/windows_entry.py
```

شغّل `dist\Daleel.exe` للتجربة أو اسحب عليه ملف SQLite مصرحًا به. خصص توقيع توزيع مستقل عند إصدار نسخة تجارية.
