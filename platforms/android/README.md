# دليل لأندرويد

نواة Python تعمل على الهاتف، وتُعرض مساحة العمل العربية في متصفح الهاتف. افتح التطبيق ثم اختر بيانات التدريب أو اختر نسخة SQLite مصرحًا لك بقراءتها. يقرأ دليل نسخة العمل من ذاكرة التطبيق المؤقتة ويحتفظ بالإجراءات والتفضيلات في مساحة التطبيق الخاصة. أكمل استخدام المتصفح دون إيقاف تطبيق دليل. عند انقطاع الجلسة ارجع إلى دليل وافتح جلسة جديدة.

## بناء APK للتجربة

المشروع يستهدف Android 7.0 فأحدث على أجهزة ARM ذات 64 بت ومحاكيات x86-64. يحتاج البناء إلى JDK 17 أو أحدث وGradle 8.13 وAndroid SDK 36 وPython 3.13. افتح مجلد `platforms/android` في Android Studio أو نفّذ من جذر المستودع:

```bash
gradle -p platforms/android :app:assembleDebug
```

مسار APK بعد نجاح البناء هو `platforms/android/app/build/outputs/apk/debug/app-debug.apk`. مهمة Android في GitHub Actions تبني هذه النسخة وتتحقق من توقيع الاختبار. لطرح نسخة إنتاجية، ابنِ إصدارًا موقّعًا بمفتاح توزيع مستقل واختبره على الأجهزة المستهدفة.

## تشغيل النسخة المحلية باستخدام Termux

هذه الطريقة تشغّل إصدار Python نفسه من الهاتف دون الحاجة إلى بناء APK.

1. فك ضغط الحزمة في مجلد التنزيلات. أبقِ مجلد `python` بجوار `run-termux.sh`.
2. افتح Termux وشغّل `pkg install python`. إذا كانت الحزمة في التنزيلات، يمكن منح Termux الوصول إليها من خلال `termux-setup-storage` واختيار السماح من النظام.
3. انتقل إلى مجلد الحزمة وشغّل `sh run-termux.sh`، ثم افتح رابط الجلسة المطبوع في متصفح الهاتف.
4. لاستخدام بياناتك، شغّل `sh run-termux.sh "/path/to/approved-snapshot.db"` مع نسخة SQLite مصرح بها ومهيأة وفق مخطط دليل. تبقى الذاكرة في مجلد Termux الخاص.

حزمتا أندرويد تشغّلان مساحة العمل المحلية. وظائف قراءة واجهات برامج الويب تظل ضمن إضافة Chrome على الكمبيوتر.
